I’m building hands-on data pipelines to become a data engineer. This repo holds the projects I build along the way, from SQL basics to a scheduled, tested pipeline.



\## Data Source



Formula 1 World Championship (1950 - 2024) by Rohan Rao (Vopani), hosted on Kaggle:

https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020



The data originates from the Ergast F1 API and is licensed CC0 (public domain).
